# Перелёт НОО → орбита у точки L2 системы Солнце—Земля

Расчёт затрат характеристической скорости по заданию (`../Sergio_doc/Zadanie_neyronke.docx`:
сухая масса КА 1800 кг, космодром Восточный, разгонный блок КВТК делает перелёт (оба
импульса), высота НОО 200 км, поддержание орбиты — СПД-100ВМ с бюджетом не более 100 м/с
в год (по возможности минимальный), форма и прецессии лунной орбиты не учитываются, тип
орбиты у L2 выбирается самостоятельно). Первое приближение — круговая ограниченная задача
трёх тел (CR3BP); затем та же трасса пересчитана в расширенной модели сил.

## Результат

| Величина | Значение |
|---|---|
| dv₁ — разгонный импульс с НОО | **3195 м/с** (скорость после импульса 10,98 км/с при v_I = 7,79 км/с) |
| dv₂ — тормозной импульс, выход на гало | **114 м/с** |
| Суммарно dv (оба импульса делает РБ) | **3309 м/с** |
| Время активного перелёта | 141 сут |
| Целевая орбита (выбрана расчётом) | гало у L2: амплитуда по z 24 553 км, по x 247 550 км, период 180,4 сут |
| Удержание | **0,77 м/с/год** при допуске ±100 км — в 130 раз ниже лимита задания; ксенон 0,09 кг/год, 4 ч работы/год |
| Топливо РБ (Isp 445 с) | 3523 кг; ксенон КА 5,7 кг; **ввести на НОО 6629 кг** (с 5 % запаса — 6885 кг) |
| Бюджет миссии с учётом возмущений | 3,41…3,69 км/с |

Сверка: для перелёта КА «Спектр-РГ» в работе Боровина, Ильина и др. (см. «Источники»)
приведён импульс перехода **3,195 км/с** при наклонении орбиты выведения **51,611°** — то же
значение и то же наклонение, что получены здесь. Период гало 180 сут согласуется с SOHO и
ACE (178 сут). Параметры СПД-100ВМ взяты из табл. 3 статьи ОКБ «Факел» (`36-55.pdf`):
тяга 90 мН, Isp 15 696 м/с (1600 с), 1350 Вт, ресурс >15 000 ч, >13 000 включений.

## Как запустить

```bash
python3 -u l2_transfer.py           # основной расчёт -> result.txt   (~6 мин)
python3 -u l2_transfer.py --check   # проверка ядра модели (~2 с): L2, C(L2), v НОО,
                                    # предельный случай e=0, замыкание гало, интеграл
                                    # Якоби, dv1, порог выхода гало из тени Земли
python3 -u l2_perturb.py            # возмущения на той же трассе -> perturb.txt (~2 мин)
node make_docx.js                   # отчёт Raschet_L2_perelet.docx из result.txt/perturb.txt
```

`l2_perturb.py` читает целевую орбиту, угол старта и dC **из `result.txt`**, а `make_docx.js`
парсит оба протокола: документ и второй расчёт не могут разойтись с основным.

Зависимости: Python 3 с numpy и scipy (проверено на 3.14 / numpy 2.5 / scipy 1.18);
для отчёта — `docx@9` (`npm install`), LibreOffice только для контроля вёрстки.

## Что внутри

| Файл | Назначение |
|---|---|
| `l2_transfer.py` | модель CR3BP: L2 из условия ∂Ω/∂x = 0; линеаризация (λ, ω_z); семейство гало продолжением от планарного семейства Ляпунова; **тень Земли для каждой орбиты** (полная/полутень) и бинарный поиск порога Az_min; dv₁ из интеграла Якоби; прицеливание (угол старта, избыток энергии) до пересечения с целевой орбитой; dv₂ как невязка скоростей; массы РБ и СПД |
| `l2_perturb.py` | та же трасса: наклон плоскости выведения (Восточный), давление Солнца и тень, Луна на круговой орбите в эклиптике (+ измерение исключённых по заданию членов), эллиптическая орбита Земли, J2 и площадка, удержание на гало и ресурс СПД-100ВМ |
| `make_docx.js` | сборка отчёта: числа **парсятся** из `result.txt` и `perturb.txt` |
| `result.txt`, `perturb.txt` | протоколы расчётов — первоисточник всех чисел |
| `Raschet_L2_perelet.docx` | отчёт (11 стр., A4, Times New Roman 14 пт, 1,5 интервала) |

## Ключевые допущения

- **Наклонение не входит в бюджет dv₁** — и не потому, что повезло с площадкой: величину
  разгона назначает интеграл Якоби на радиусе НОО, она не зависит от наклона (проверено
  числом: разброс 0,0 м/с при наклоне плоскости 0…75°). Наклонение задаёт **плоскость**
  трассы. С Восточного (i = 51,6°) плоскость можно повернуть к эклиптике не более чем на
  i − ε = 28,2°, и это стоит тех же ~110 м/с во втором импульсе, что и трасса в эклиптике
  (109 м/с против 114 м/с). Не поворачивать плоскость к эклиптике — платить +41 м/с (51,6°)
  или +75 м/с (75°, худшая расстановка узлов). Строго цена снимается выбором гало с
  наклонением, равным наклонению трассы (правило подбора из работы Боровина и др.);
  наклонное семейство здесь не рассчитано — таблица даёт верхнюю оценку.
- **Тип орбиты выбран по двум критериям**: минимум суммарного dv и полный выход из конуса
  тени Земли. Полная тень до L2 не дотягивается (её конус заканчивается в 1 382 030 км,
  L2 — 1 501 532 км), а радиус полутени на расстоянии L2 — 13 421 км; расчёт по самой
  орбите даёт порог Az_min = 12 276 км. Взято Az = 2·Az_min (запас на ±1,7 % изменения
  расстояния Солнце—Земля за год и на наклон трассы). Минимальная по dv орбита (Az = 4488 км)
  каждый период проходила бы через полутень — это сброс давления Солнца и питания, т.е.
  прямой удар по бюджету удержания, которое по заданию требуется минимизировать.
- **Удержание лимитируется допуском, а не динамикой**: 0,77 м/с/год при ±100 км, 7,7 м/с/год
  при ±1000 км. Лимиту задания 100 м/с/год соответствует допуск ±13 000 км по месту.
  Даже сам лимит умещается в один СПД-100ВМ: 556 ч работы в год и 11,4 кг ксенона = 19 %
  ресурса за 5 лет и в 167 раз меньше лимита включений.
- **Луна — по заданию**: круговая орбита в эклиптике, без прецессий. Исключённые члены
  измерены, чтобы видеть цену: форма орбиты и прецессии узла/апсид дают −88…+253 м/с в dv₂,
  т.е. исключение — требование задания, а не вывод расчёта.
- Место включения первого импульса смещено из эклиптики на r_p·sin 28,2° ≈ 3100 км
  (0,2 % масштаба трассы) — пренебрежено.
- Цена эксцентриситета Земли — +34 м/с в dv₁; большие значения dv₂ в эллиптической модели
  измеряют неверность цели (в ER3BP орбиты у L2 квазипериодические и меняют размер вместе
  с расстоянием Солнце—Земля), а не стоимость.

## Чего в расчёте нет

Наклонного семейства гало (см. выше — оно сняло бы цену плоскости полностью). Корректной
проверки выполнимости по носителю: **ТТД разгонного блока КВТК в доступных источниках не
найдены** (`grep` по всем PDF в `../Sergio_doc/` — ноль совпадений), поэтому Isp = 445 с и
сухая масса РБ 1300 кг приняты как допущение с чувствительностью ±10 с, а 6629…6885 кг на
НОО поданы как *требование* к грузоподъёмности, а не как вывод о совместимости. Широта
Восточного также не подтверждена источником — в расчёте используется только наклонение 51,6°.
Кроме того: коррекции середины трассы и реальная схема удержания (бюджет дан через e-folding),
полутень на трассе (верхняя оценка ≤ 39 мм/с), переориентация КА (C_R постоянен), эволюция
орбиты на сроки много длиннее периода, J2 в уравнения движения. Выигрыш гравманёвра у Луны
при двух свободных параметрах прицела не находится (лучший из 5 ходов +77 м/с).
