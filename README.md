# Перелёт НОО → орбита у точки L2 системы Солнце—Земля

Расчёт затрат характеристической скорости по заданию (`Zadanie_neyronke.docx`:
масса КА 2500 кг, наклонение НОО 23,5°, высота 200 км, два импульса — разгонный и
тормозной, тип орбиты у L2 выбирается самостоятельно). Первое приближение — круговая
ограниченная задача трёх тел (CR3BP); затем те же трассы пересчитаны в расширенной
модели сил.

## Результат

| Величина | Значение |
|---|---|
| dv₁ — разгонный импульс с НОО | **3195 м/с** (скорость после импульса 10,98 км/с при v_II = 11,01 км/с) |
| dv₂ — тормозной импульс, выход на гало | **104 м/с** |
| Суммарно dv | **3299 м/с** |
| Время активного перелёта | 140 сут |
| Целевая орбита (выбрана расчётом) | гало у L2: амплитуда по z 4488 км, по x 247 118 км, период 180,4 сут |
| Топливо при m₀ = 2500 кг | 1598 кг (Isp 330 с) … 1958 кг (Isp 220 с) |
| Бюджет миссии с учётом возмущений | 3,40…3,50 км/с |

Сверка: для перелёта КА «Спектр-РГ» в работе Боровина, Ильина и др. (см. «Источники»)
приведён импульс перехода **3,195 км/с** — то же значение, что получено здесь, при
другом наклонении орбиты выведения (51,6°) и другой амплитуде целевой орбиты.
Период гало 180 сут согласуется с SOHO и ACE (178 сут).

## Как запустить

```bash
python3 -u l2_transfer.py           # основной расчёт -> result.txt   (~5 мин)
python3 -u l2_transfer.py --check   # проверка ядра модели (~35 с): L2, C(L2), v НОО,
                                    # предельный случай e=0, замыкание гало, интеграл
                                    # Якоби, dv1
python3 -u l2_perturb.py            # возмущения на той же трассе -> perturb.txt (~9 мин)
node make_docx.js                   # отчёт Raschet_L2_perelet.docx из result.txt/perturb.txt
```

Зависимости: Python 3 с numpy и scipy (проверено на 3.14 / numpy 2.5 / scipy 1.18);
для отчёта — `docx@9` (`npm ci`) и LibreOffice только для контроля вёрстки.

## Что внутри

| Файл | Назначение |
|---|---|
| `l2_transfer.py` | модель CR3BP: L2 из условия ∂Ω/∂x = 0; линеаризация (λ, ω_z); семейство гало продолжением от планарного семейства Ляпунова; dv₁ из интеграла Якоби; прицеливание (угол старта, избыток энергии) до пересечения с целевой орбитой; dv₂ как невязка скоростей в точке входа; расход топлива |
| `l2_perturb.py` | та же трасса с давлением Солнца, Луной (наклонение 5,1°, e = 0,055, прецессии узла и апсид), эллиптической орбитой Земли; оценки полутени, J2/площадки, удержания на гало; поиск выгоды гравманёвра |
| `make_docx.js` | сборка отчёта: числа **парсятся** из `result.txt` и `perturb.txt`, поэтому документ не может разойтись с расчётом |
| `result.txt`, `perturb.txt` | протоколы расчётов — первоисточник всех чисел |
| `Raschet_L2_perelet.docx` | отчёт (7 стр., A4, Times New Roman 14 пт, 1,5 интервала) |

## Ключевые допущения

- Наклонение 23,5° не входит в бюджет dv: долгота узла и момент старта выбираются так,
  чтобы вектор разгона лежал в плоскости НОО (разворота плоскости нет). Дрейф узла из-за
  J2 равен −8,21 °/сут, направление на L2 уходит на 0,99 °/сут — совпадение повторяется
  каждые 39,1 сут (~9 окон в году). При рассогласовании 5 / 10 / 20° dv₁ вырастает до
  3295 / 3579 / 4531 м/с. Само наклонение 23,5° требует площадки с широтой ≤ 23,5°.
- Место включения первого импульса смещено из эклиптики на r_p·sin i = 2620 км (0,2 %
  масштаба трассы) — пренебрежено; эклиптика — инвариантная плоскость CR3BP.
- Луна и возмущения моделируют несоответствие расчётной модели реальному движению, а не
  перестраивают семейство орбит. Цена эксцентриситета Земли — +33 м/с в dv₁; большие
  значения dv₂ в эллиптической модели измеряют неверность цели (в ER3BP орбиты у L2
  квазипериодические и меняют размер вместе с расстоянием Солнце—Земля), а не стоимость.

## Чего в расчёте нет

Коррекций середины трассы и реальной схемы удержания (оценка: 0,77 м/с/год при допуске
±100 км — динамическое требование, без запаса на исполнение РД и навигацию), полутени
(дана верхней оценкой: ≤ 28 мм/с), переориентации КА (C_R постоянен), давления
излучения в удержании, LISA-подобных трасс и гравманёвра как отдельной задачи — при
двух свободных параметрах прицела (угол старта и энергия) выигрыш от Луны не находится:
лучшие из 5 пересечений дают +60 м/с.
